# 版本记录

## 0.2.5 — 2026-10-20

- 整理 V3 交付，新增 `START_HERE_V3.md` 和工作区根目录 `V3_使用与路径.md`，列清当前模型、标签、报告、历史版本及运行命令。
- 新增 `run_v3.ps1` 与 `segment_v3.cmd`，串联现有分割及加视角复核；任务缓存统一位于 `segmentation/` 与 `extra_views/`，成功后写 `result_paths.txt/json`。`-ExtraViews 0` 可跳过新增视角；旧入口继续兼容。

- 算法、阈值、既有模型及标签保持原样；新增分发检查后共 30 项回归。

## 0.2.4 — 2026-10-20

- 新增可选 `run_extra_views.ps1` / `extra_view_review.py`：从不确定表面的面积覆盖选择相隔较远的相机，补充盆内俯视角，运行原 v3 的 GroundingDINO + CLIPSeg + MobileSAM，并做逐顶点深度检查。默认完整流程保持原有推理量，不调用 SAM3。
- 语义标签和分数冻结；至少 3 个新增相机支持、同意率 ≥70%、领先竞争类 ≥30% 且满足分数条件才解除历史标记。强竞争类共识会新增冲突标记；所有观测包括弃权都计入分母。相隔较远的视角不代表统计独立。
- 本株新增 14 个视角，解除 75,475 个标记、新增 7,440 个冲突，391,087 → 323,052（24.95% → 20.61%）。基质 6,901 → 7,271，主要收益在花瓣背面。输出位于 `outputs/plant_semantics_v3_extra_views/complete/`；各历史结果保留。
- 新增 8 项视角选择、证据约束和无效输入回归，共 29 项。提供单独入口、历史标记及审计字段，源码包收录本步骤；减少标记不等于语义准确率提高。

## 0.2.3 — 2026-10-20

- 默认继续使用 v3 模型组合（GroundingDINO、CLIPSeg、MobileSAM），不调用或加载 SAM3。
- 新增 `reassess_uncertainty.py`：在原语义标签和分数不变的前提下，根据最终独立相机支持或叶面掩膜确认，解除满足规则的历史不确定标记；原始标记保存在 `uncertain_before_reassessment`。
- 单纯高分、少于 3 相机的支持、仍有冲突的证据及无独立掩膜确认的几何叶缘修改，不足以解除标记。不确定比例变化不代表准确率提高。
- 原植物复核版为 `outputs/plant_semantics_complete_v3_reviewed`：477,072 → 391,087 个标记（30.43% → 24.95%），解除 85,985 个；基质 13,167 → 6,901 个。原 v3 保持不变。
- 自动入口增加 `complete_before_uncertainty/` 阶段，最终位置仍为 `complete/`；新增复核规则/数据一致性测试，现共 21 项回归。

## 0.2.2 — 2026-10-20

- 新增 `refine_leaf_rim.py`：多视角修复之后，依据冻结的叶片连通区域、窄范围网格距离与体素均匀采样的叶面支持，补全残留的茎色叶缘。不读取 RGB，不要求卷曲叶缘满足平面形状门槛。
- 只允许茎→叶；受保护花苞、花、盆及基质不被改写。路径只经过未保护的茎/叶顶点；不跨不连通表面，新增叶点不继续生长。真实叶柄交界及重建粘连仍可能有歧义。
- 自动入口新增 `complete_before_rim/` 中间阶段，最终位置仍为 `complete/`。提供单独诊断、前后对比和可追溯配置；新增改动点标记为不确定。
- 原植物 v3 相比 v2 将 2,534 个茎标签顶点改为叶片，约占总表面积 0.1706%。这不是语义准确率；原模型及 v2 文件保留。
- 新增 4 项叶缘行为回归测试；源码包包含新阶段和测试。
