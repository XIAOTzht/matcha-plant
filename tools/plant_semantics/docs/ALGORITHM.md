# 算法流程与参数

## 输入和标签

输入是带逐顶点 RGB 的三角网格 PLY，坐标有限且已竖直摆正。输入应只含植物、花盆/托盘和盆内基质；纯点云、只有纹理贴图或无 RGB 的网格需先转换。当前面向单株，盆口模块含紧凑近圆单盆的假设。

| ID | 类别 | 语义显示 RGB |
| --- | --- | --- |
| 1 | 枝干、茎、叶柄、花梗 | 245, 155, 35 |
| 2 | 叶片 | 40, 190, 85 |
| 3 | 花、花苞 | 235, 75, 165 |
| 4 | 花盆、托盘 | 55, 130, 240 |
| 5 | 土壤、基质 | 140, 95, 55 |

所有顶点和面最终赋予 1–5 标签。允许某类为 0 个，不强求五类都存在。`uncertain` 单独记录证据不足；完整赋类不代表全部正确。中间阶段的 label=0 用于拒识，最终文件不保留该类别。

## 自动处理

1. **全局渲染**：Open3D 射线渲染 14 个视角，保存像素对应三角面及重心坐标。
2. **二维语义**：冻结的 GroundingDINO-Tiny 产生候选框，CLIPSeg 提供文本语义分数，MobileSAM 细化掩膜。三者均使用公开权重，SAM3 未参与。
3. **回投三维**：逐原顶点投影并检查射线遮挡，融合可见相机证据。
4. **局部细化**：自动选择细茎及可用盆口放大视角；双尺度 PCA 提供线性/平面形状辅助。同一相机的多个裁剪共享一次投票，避免重复计票。
5. **完整五类**：重新融合实例支持、保护花苞，以自动伪标签拟合当前场景 Lab 颜色 GMM，并沿真实网格边传播。所有顶点及三角面完成五类赋类。
6. **叶缘修复**：从有把握的叶片连通核心自动生成内部正提示与其他器官负提示，调用 MobileSAM 重勾叶面。增加斜下方 12 个方向；多相机一致且在叶片邻近表面上的茎/花点可改为叶片。
7. **窄叶缘补全**：冻结已有可靠叶片连通区域，仅在未保护的茎/叶网格上计算最短路径。窄范围内的茎标签点还需足够的邻域叶面支持才能改成叶；新增点不参与继续扩张。
8. **导出和验证**：保存原索引模型、标签、预览及诊断记录，核验序列化结果。

从 0.2.3 开始，在最终导出前附加历史不确定标记复核：综合最终分数与至少 3 个独立相机的器官实例支持或叶面掩膜证据，只解除符合规则的历史标记，不修改类别和分数。几何修改的窄叶缘必须有独立叶面掩膜确认。原始标记另存，规则与局限详见 [UNCERTAINTY.md](UNCERTAINTY.md)。默认主线仍是 v3，不调用 SAM3。

核心模型不训练、不需要人工框点。GMM 是对当前输入自动拟合的辅助外观分布，不是基础模型微调。

## 为什么叶缘会出现橙色、粉色

薄叶边缘在渲染中只有少量像素，像素可能混入背景或相邻器官。重建粘连、遮挡、细茎与叶片交接也会让二维语义及三维传播在边缘混淆。原模型局部颜色噪声会进一步影响外观辅助项。

当前叶缘修复增加了完整叶面实例证据和下方视角，并只沿网格连接、限定距离修改。既有叶片、盆、基质与受保护花苞不被此步骤改写。极细边缘、叶基部及真实粘连处仍可能有残余误差。

0.2.2 增加窄叶缘补全：卷曲、增厚的叶缘有时呈细长形状，不能强制要求其满足局部平面判据。新步骤检查它是否紧邻已确定的叶面。几何归一化后进行体素均匀采样，以高斯权重（标准差为邻域半径的 0.6 倍）估计叶片支持，减轻三角面密度差异的影响。仅修改茎→叶，不改花或其他类别；不使用颜色阈值。

欧氏邻域支持不是连通性证据，必须先通过真实网格最短路径门槛。路径不能经过花、盆、基质或受保护顶点。叶片种子不更新，阶段拒绝把已补全的结果再次作为输入；完整入口每次从前阶段重新计算，避免多轮累积扩张。真实叶柄就在叶面连接处时仍可能歧义，这条规则不能保证所有枝干都不受影响。

新增点被标为 `uncertain=1`，标签仍为叶片。启发式分数向叶片混合 0.55 权重，只用于结果一致性及三角面赋类，不代表预测正确的概率。`rim_diagnostics.npz` 仅按候选索引存储诊断；`rim_config.json` 保存参数与输入/代码哈希。

## 花色和枯黄叶

模型接收的是“叶、花、茎”等语义提示，没有把粉色定义成花，也没有把绿色定义成叶；外观 GMM 根据每个新输入自动拟合。因此流程支持处理白花、紫花及黄叶，但这些情况尚无独立精度测试。若二维模型没有找到某器官，自动伪标签也可能不足，不能仅凭这套结构保证识别正确。
