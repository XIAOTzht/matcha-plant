# 更明显的绕行与关节配合

`demonstration_motion.py` 是可选的展示偏好搜索，在已验证自然路线基础上增加抬肘、提前转腕和侧向绕行。路线复杂度本身不是低接触代价的证据，也不代表算法全局最优。

搜索通过固定种子的低频关节姿态偏移生成完整路线，保持原起终点、闭合夹爪和最终土壤目标。部分候选仅调整早段、保留末段，其他候选采用更宽的姿态变化。每条候选重新求解固定 C3 七次曲线的共享导数和逐段时长。粗筛和最终 5 ms MuJoCo 动态检查使用相同模型、权重、逆动力学前馈和速度/加速度限制。

配置 `simulation/configs/demonstration_motion.json` 包含：

- 搜索预算 480 s，最多 8 条密集动态复查，种子 20261109。
- 总时长不超过 20 s，原有每关节最多一次 3° 明显换向、途中低速不超过 0.5 s、归一化 jerk 不高于输入基准。
- 实际持续接触惩罚不高于输入自然路线，按完整精度比较；硬障碍规则不变。
- 喷口路线相对基准的最大空间偏离至少 45 mm，峰值高度增加至少 25 mm，肘部与腕旋转活动至少 38°、55°。
- 喷口长度最多为基准的 1.7 倍，关节总行程最多为 1.65 倍；展示偏好在各目标达到预期后饱和，禁止无限奖励多绕圈。

偏离量为候选各喷口位置到基准曲线的最近距离中的最大值；不是候选整条路线都保持该距离。高度差比较两条路线的最高喷口位置。最终额外检查实际仿真轨迹的这些指标，保存在 `demonstration_verification.json`。`validation_report.json` 仍是原有 20 项物理和运动约束报告。

只有同时通过动态检查和展示门槛才更新最新路径；`--no-promote` 可以只生成独立候选。未找到满足条件的路线时，`demonstration_selection.json` 保留输入基准。自然模式、旧协同模式和代价优先模式继续可用。

完整流水线配置的 `simulation_demonstration_config` 启用 `06d_demonstration`，位于自然阶段之后、最终动态复查和渲染之前。删除该键可以回到自然模式。搜索选择、搜索报告和实际展示指标随下载结果导出。旧流水线结果保持不变；代码与配置改变后使用新 RunName。

本轮 Windows 本地结果为 `simulation/outputs/demonstration_20261108_v1`。未上传服务器。接触得分是加权几何代理，未模拟植物变形和真实接触损伤；路线长短及可见动作幅度单独报告，不能替代代价和约束验证。
